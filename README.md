## 🚀 Featured Projects

### 🏠 [House Price Prediction – Advanced Regression](https://github.com/syedabar02/house-price-prediction)
> **DataMites Capstone Project | PRCP-1020**

Predicted residential house prices using the Ames Housing dataset (79 features, 1460 homes).

- **EDA:** Distribution analysis, correlation heatmap, box plots for outlier detection, categorical feature analysis
- **Feature Engineering:** 14 new features (TotalSF, HouseAge, QualArea, etc.)
- **Preprocessing:** Semantic missing value imputation, log transformation, SelectKBest feature selection
- **Models:** 9 algorithms — Linear, Ridge, Lasso, Decision Tree, Random Forest, GBM, XGBoost, LightGBM
- **Tuning:** RandomizedSearchCV hyperparameter optimization
- **Best Result:** Blended ensemble with strong R² and low RMSE
- **Extra:** Neighborhood-based customer buying recommendations

`Python` `Scikit-learn` `XGBoost` `LightGBM` `Pandas` `Seaborn`

### ✈️ [Flight Fare Prediction](https://github.com/syedabar02/flight-fare-prediction)
> **DataMites Capstone Project | PRCP-1025**

Predicted Indian domestic flight ticket prices using airline, route, timing, and duration features.

- **EDA:** Airline price analysis, source/destination trends, stops impact, seasonal pricing patterns
- **Feature Engineering:** DateTime parsing (day/month/hour), Duration string → minutes, ordinal encoding for stops
- **Preprocessing:** SelectKBest feature selection, log transformation of skewed target
- **Models:** 9 algorithms — Linear, Ridge, Lasso, Decision Tree, Extra Trees, RF, GBM, XGBoost, LightGBM
- **Tuning:** RandomizedSearchCV on best model
- **Best Result:** Gradient Boosting — **R² = 0.8749, MAE = Rs. 1,219**
- **Key Finding:** Airline and Duration are the strongest price predictors

`Python` `Scikit-learn` `XGBoost` `LightGBM` `Pandas` `Seaborn`
